# AIChatApp

 this is an compose-kt app that allows the users to use any model and talk to them

### personal note -

I like ambitious ideas, simple systems, and software that feels obvious. Do not preserve complexity just because it already exists. Do not introduce machinery because it looks architecturally impressive. Understand the real constraint, then fight for the smallest model that makes the correct behavior unsurprising. I want you to follow the docs in doing stuff eg when working on the Android app follow the compose docs like how to structure the app, files, arch etc and same for the backend that use Cloudflare worker.
think of rest of this docs as more of good practice and not hard rules

### Rules

* do not write comments
* when you try to run assemble debug etc, ask me via question before running it
* don't write test until I tell you
* I want you to abstract the code only when you see it being repeated more than one time, also use clear variable names
* no regex and no slop code
* if the lib used contains the functionality then use that and don't reinvent the wheel
* my app uses Layered architecture
* see Backend.md when working on backend

### code-style

* abstract only when seeing a pattern and see the code repeating
* try to not have code bloat
